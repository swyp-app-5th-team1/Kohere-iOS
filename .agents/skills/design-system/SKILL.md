# Design System

## Purpose

Kohere의 디자인 시스템을 iOS 코드에 적용하거나 정리할 때 사용한다.

## Context

- 먼저 `AGENTS.md`를 확인한다.
- 디자인 시스템 기준은 `docs/design-system.md`를 확인한다.
- 미확정 기준은 넘겨짚지 말고 사용자에게 질문한다.

## Workflow

1. 작업 범위가 color, typography, spacing, elevation, component 중 무엇인지 구분한다.
2. 기존 프로젝트 구조와 네이밍을 먼저 확인한다.
3. 확정된 규칙 안에서 최소 범위로 구현하거나 문서를 수정한다.
4. 새 규칙이 필요하면 구현 전에 사용자에게 선택지를 제시한다.
5. 검증한 항목과 검증하지 못한 항목을 마지막에 정리한다.
