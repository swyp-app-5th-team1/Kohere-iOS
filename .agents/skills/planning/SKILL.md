# Planning

## Purpose

구현 전에 요구사항을 구체화하고, 확정/미확정/보류 항목을 정리할 때 사용한다.

## Context

- 먼저 `AGENTS.md`를 확인한다.
- 기능 계획과 미확정 요구사항은 `docs/planning.md`를 확인한다.
- 확정된 결정은 필요하면 `docs/progress.md`에 반영할지 제안한다.

## Workflow

1. 사용자의 설명을 바탕으로 목표와 범위를 정리한다.
2. 부족한 정보는 한 번에 너무 많이 묻지 말고 필요한 순서대로 질문한다.
3. 선택지가 있으면 장단점과 추천안을 함께 제시한다.
4. 확정, 미확정, 보류 항목을 구분한다.
5. 구현 가능한 작업 단위로 나눈다.
6. 사용자가 요청하기 전에는 구현하지 않는다.
